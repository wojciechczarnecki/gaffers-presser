# Architecture decision records

`docs/DECISIONS.md` is the log: one row per binding decision. A decision that had real
alternatives worth explaining also gets an ADR here, and its row links to it.

- File name: `NNNN-<slug>.md`, numbered in order.
- Sections: Status, Context, Options, Decision, Consequences.
- Status: `accepted`, or `superseded by NNNN`. An accepted ADR is not rewritten; a change
  of mind is a new ADR that supersedes it.
